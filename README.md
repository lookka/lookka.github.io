# Sito personale

## Prima di pubblicarlo

1. Your name, degree and introductory copy are already filled in. Add your University email and GitHub link when you are ready.
2. Put PDFs in a `dispense` folder (create it when needed), then add their filename to a note card in `index.html`.
3. The original notes are licensed under CC BY-NC-SA 4.0. Keep the `LICENSE.md` file when publishing and add the same licensing notice to the first or last page of every PDF.

## Pubblicazione su GitHub Pages

1. Crea su GitHub un repository pubblico dal nome esatto `tuo-username.github.io`.
2. Carica qui dentro `index.html`, `style.css` e la cartella `dispense`.
3. Nel repository apri **Settings**, poi **Pages**. In *Build and deployment* scegli **Deploy from a branch**, seleziona `main` e la cartella `/(root)`, quindi salva.
4. Dopo pochi minuti visita `https://tuo-username.github.io`.

Il sito è statico: i PDF e le modifiche restano sotto il tuo controllo nel repository.
